# BloodBridge 🩸

BloodBridge is a full-stack web platform designed to connect blood donors with recipients efficiently and reliably. The system helps streamline the blood donation process by enabling users to register as donors, request blood, search for compatible donors, and manage donation-related activities in a centralized platform.

---

## Project Overview

Access to blood during emergencies can be difficult and time-sensitive. BloodBridge aims to reduce delays by creating a digital bridge between donors and recipients.

The platform focuses on:

* Fast donor-recipient connection
* Blood type matching
* User-friendly experience
* Secure and scalable architecture
* Real-time accessibility through the web

## Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm or yarn
* Java JDK 17+
* Maven

---

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Frontend will run on:

```bash
http://localhost:5173
```

---

## Backend Setup

```bash
cd backend

./mvnw spring-boot:run
```

Or on Windows:

```bash
mvnw.cmd spring-boot:run
```

Backend will run on:

```bash
http://localhost:8080
```
